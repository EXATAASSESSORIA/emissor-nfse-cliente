# Emissor de NFS-e — EXATA Assessoria Contábil

Instalador e atualizações do Emissor de NFS-e oferecido pela EXATA Assessoria Contábil aos seus clientes.

**Instalação:** baixe o arquivo `Instalar-Emissor-NFSe.zip` do lançamento mais recente, extraia e execute `INSTALAR.bat`.
O programa se atualiza sozinho pela internet. A emissão exige licença de uso fornecida pelo escritório EXATA.
